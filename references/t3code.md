# T3 Code でメンバーを呼ぶ

`delegate_task` が使えるときの呼び出し方です。

このファイルの内容は、T3 Code v0.1.0 のリリースノートと利用者の報告をもとに書いています（末尾の出典）。公式の仕様書を写したものではありません。**実際に使えるツールの定義とこのファイルが食い違ったら、ツールの定義に従ってください。**

## 流れ

### 1. 使えるプロバイダーを調べる

`orchestrator_capabilities` を引数なし（`{}`）で呼び、プロバイダーとモデルの正確なIDを得ます。表示名とIDは一致しないことがあるので、推測で書かないでください。子タスクを動かせるもの（`canRunChildTask` が真）だけを使います。

### 2. 割り当てを決める

- プロバイダーが2つ以上使えるなら、少なくとも1人は進行役と別のプロバイダーで動かす。
- 1つしかないなら、同じプロバイダーの別モデルに分ける。
- それもできないなら、全員を同じモデルで動かす。この場合、意見が似やすいことを地図を出すときに一言伝える。

割り当ての目安です。

| 顔ぶれ | 向いている割り当て |
|---|---|
| 現場の人 | コードを読むのが得意なもの。進行役と同じでよい |
| 攻める人、そもそもの人 | 進行役と別のプロバイダー。見落としの重なりを減らすため |
| 外の人 | ウェブ検索ができるもの |

### 3. 送り出す

メンバーごとに `delegate_task` を1回ずつ呼びます。3人分を同じ発言の中で続けて呼び、並行して動かします。

```json
{
  "task": "<members.md のひな形で書いた依頼文>",
  "target": { "providerInstanceId": "<IDその1>", "model": "<モデルID>" },
  "mode": "async",
  "role": "research",
  "clientRequestId": "monju-<議題の短い名前>-r1-<役割>"
}
```

- `task` は単独で読める文にする。メンバーは親の会話を見ていない。
- `target` を省くと、進行役と同じプロバイダーとモデルで動く。
- `role` はツールの定義にある値から、読み取り専用の調査に合うものを選ぶ。
- `clientRequestId` は、メンバーと巡ごとに別の値にする。同じ依頼をやり直すときは同じ値を使う。
- 返ってきた `taskId` を控える。
- モデルIDが拒否されたら、`orchestrator_capabilities` の一覧にある近いものに替え、替えたことを伝える。

### 4. 結果を待つ

送り出したあと、「戻るまでに、もしよければ」の問いを添えて発言を終えます。

- 結果がまとまって自動で戻ってくる環境では、そのまま待つ。
- 戻ってこない環境では、`task_status` に `taskId` を渡して確かめる。短い間隔で何度も呼ばない。
- 止まったままのメンバーがいたら `task_cancel` で止め、残りの回答だけで地図を出す。誰が欠けたかを伝える。

メンバーの回答が形式を守っていなくても、やり直させずに使います。長すぎる回答は、進行役が【立場】【根拠】【気になる所】を抜き出します。

### 5. 2巡目

2巡目は、新しい `delegate_task` として送ります。新しい `clientRequestId` をつけ、必要な文脈を依頼文に書き直します。1巡目の子スレッドにメッセージを送って続きを頼まないでください。子スレッドは読み取り専用です。

## やってはいけないこと

- **プロバイダーの切り替えで視点を変えようとしない。** スレッドの途中でプロバイダーを替えると、それまでの推論やツールの結果が引き継がれない。別の視点がほしいときは `delegate_task` を使う。
- **新しいスレッドを立てるツール（`t3_thread_launch` など）でメンバーを呼ばない。** 子タスクではなく独立したスレッドになり、この合議の一部として扱えなくなる。
- **`delegate_task` が使えるのに、プロバイダー内蔵のサブエージェントで済ませない。** 内蔵のものは進行役と同じプロバイダーでしか動かず、別プロバイダーの視点を入れられない。

## 寄り道のフォーク

問いの意味を確かめる寄り道が長引いたら、ユーザーにスレッドのフォークを勧めます。フォークは終わった実行からならどこからでも作れます。寄り道が済んだら、フォーク先の文脈は元に**戻さず**、わかったことだけをユーザーが持ち帰ります。戻すと、本筋の文脈に寄り道のやりとりが混ざります。
