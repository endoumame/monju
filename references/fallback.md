# メンバーを呼ぶ道具がないとき

`delegate_task` もなく、herdr の中でもないときの進め方です。

## A. サブエージェントで呼ぶ

`Task` や `Agent` のように、サブエージェントを起動するツールがあるときに使います。メンバーを1人ずつ、並行して起動します。依頼文は `members.md` のひな形をそのまま使います。

別のプロバイダーは選べないので、意見が似やすいことを地図を出すときに一言伝えます。

## B. 進行役が1人で書く

サブエージェントも起動できないときの簡易版です。独立性が弱いことを、最初にユーザーに伝えます。

```
メンバーを呼べない環境なので、簡易版で進めます。3つの視点を私が順に書くため、意見が似やすくなります。
```

1. 役割を1つ選び、その役割の持ち場だけを見て、カードを書き切る。
2. 書いたカードを見返さずに、次の役割へ移る。
3. 3枚そろってから、はじめて見比べて地図を作る。

簡易版では、「軽め」で済む議題かどうかを先に考えてください。事実の確認だけで足りる議題なら、進行役が「確かめる」を使うほうが正直です。

## 寄り道

スレッドのフォークやペインの追加ができない環境では、寄り道が長引いたら、別の会話を新しく開いて聞くことをユーザーに勧めます。
